# Dan Heiwa 1.155.16 — memoria JSON/JSONL

Il pulsante Memoria di HEIWA ora offre note personali, importazione multipla di JSON/JSONL dal selettore File Android (incluso Drive), rilettura dei documenti già collegati, importazione dalla cartella Dan già autorizzata qualora disponibile, ricerca diretta nell'indice e cancellazione della sola copia locale.

Non usa credenziali Google incorporate, non rende pubblici file e non modifica gli originali. L'accesso ai file di Drive viene concesso dal selettore Android. Dopo l'indicizzazione la ricerca è locale e disponibile offline; aggiornamento dei file esplicito, dipendente dai permessi persistenti forniti dal provider. Non equivale a sincronizzazione automatica dell'intero Drive.

Parser: backup Dan JSONL con event_id/ruolo/testo/data, array di messaggi, note JSON annidate e rami attivi delle esportazioni ChatGPT. Esclude ruoli system/developer/tool, canali analysis/commentary e campi credenziali riconosciuti nelle note generiche. I dati non vengono eseguiti. Limiti per proteggere RAM e spazio: JSON 8 milioni di caratteri, JSONL 32 milioni totali e 1 milione per riga, singolo record 262144 caratteri; un errore annulla la reimportazione di quel file e conserva la precedente copia valida.

Indice SQLite/FTS separato con frammenti, ruoli, titoli e data. ID stabili per deduplicare copie dei medesimi record. Relazione file-record per mantenere le copie condivise e rimuovere solo i frammenti non più referenziati dopo la rilettura. I backup originali e le conversazioni web non sono modificati.

Ad ogni domanda locale vengono recuperati fino a tre estratti pertinenti con fonte/ruolo/data. Qwen riceve solo un contesto abbreviato, non tutti i JSON insieme; la memoria non cambia i pesi del modello. L'utente può usare Cerca nei JSON per controllare le fonti senza affidarsi alla risposta generata. Per Groq, l'invio degli estratti JSON richiede un'opzione separata, disattivata inizialmente e indipendente dalla precedente opzione delle note.

Verifiche: parser con campione reale solo sul workspace privato (nessun contenuto nei log/repository), test sintetici su JSON/JSONL, Unicode, dedup, ruoli, campi segreti, ramo attivo, dati malformati e cancellazione; schema SQLite reale con FTS Unicode, sostituzione, rollback e riferimenti tra fonti; contesto e test voce/lettura/Invio esistenti. Prova con Drive Android e recupero sul Lenovo da eseguire dopo installazione. Modello Qwen invariato: non richiede nuovo download se già importato nella 155.15.
