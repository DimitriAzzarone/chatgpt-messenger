# Dan Heiwa 1.155.5

Base: commit 0db339a9c05e16e592f82f33808c2ba807d1224b, versione 1.155.4, ramo dan-v1.155.3-upload-fix. La 1.155.4 risulta compilata con successo nel run 44172177684.

Il selettore allegati usa ACTION_OPEN_DOCUMENT con fallback ACTION_GET_CONTENT. I documenti selezionati, anche multipli, vengono preparati su un executor dedicato e copiati in cache tramite stream con buffer 64 KiB, senza leggere il file intero in RAM. La pagina riceve URI FileProvider delle copie, preservando nome e riconoscimento MIME tramite estensione. I file originali non vengono modificati. Il provider espone solo cache/attachments con permessi URI, non esportato pubblicamente.

Gestisce annullamento, errore del provider, selezione sostituita, chiusura Activity e rimozione delle copie incomplete. Le vecchie copie temporanee vengono eliminate dopo 24 ore al successivo caricamento. Controlla lo spazio disponibile per la copia. Il messaggio «File consegnati alla pagina» indica soltanto la consegna al WebView, non conferma il completamento dell’upload sul servizio.
